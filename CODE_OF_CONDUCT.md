# Code of Conduct

We want participation in this project to be safe, respectful, and productive.

Contributors must communicate constructively, respect differing experiences and viewpoints,
accept feedback in good faith, and avoid harassment, intimidation, discrimination, or disclosure
of another person's private information.

Maintainers may edit or remove contributions and restrict participation when behavior threatens
the community or project. Reports should be made privately to the security or conduct contact
published in the repository settings. Maintainers will protect reporters' privacy where possible
and respond proportionately to the circumstances.

This code applies in project spaces and when someone is publicly representing the project.
